# Third-party notices and protocol credits

ClickShift is an independent implementation. Its Bluetooth interoperability work was informed by these community projects and protocol references:

- `nrbz467bct-dot/zwift-click-keyboard-mapper` (MIT), particularly the documented Click v2 handshake, keepalive, and active-low button mask.
- `OpenBikeControl/bikecontrol`, consulted for interoperability facts such as the right-side manufacturer type and current MyWhoosh key mappings. No proprietary/private OpenBikeControl code is included.
- Makinolo's public Zwift Ride protocol notes and the `ajchellew/zwiftplay` community research.
